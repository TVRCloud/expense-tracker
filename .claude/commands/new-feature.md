---
description: Scaffold a new feature dir with its CLAUDE.md and feature-map row
argument-hint: <feature-name> <one-line purpose>
---
Create feature `$ARGUMENTS`.

1. Read `docs/feature-map.md` and one existing feature's CLAUDE.md to match conventions.
2. Create the feature dir in the repo's feature location with only the files needed.
3. Copy `docs/templates/feature-CLAUDE.md` into it and fill every section from the real code.
4. Add the row to `docs/feature-map.md`, including the counterpart in the other repo.
5. Follow `docs/templates/new-feature-checklist.md`. Do not commit.
